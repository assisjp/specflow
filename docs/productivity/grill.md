# grill

Resolve consequential uncertainty before committing to a plan.

## When to use it

Use when the user asks to pressure-test thinking or a decision, not as a mandatory prelude to all coding.

## Behavior

- Look up facts, reuse priorities and accepted decisions, recommend choices with trade-offs, and challenge contradictions that affect the outcome.
- Ask focused questions until relevant decisions are settled or intentionally deferred. Do not enumerate every imaginable branch or request confirmation of the same approval.
- Grilling itself does not authorize source edits. A later explicit implementation request changes scope and can continue through execution without another named skill command.
- In docs mode, use domain-modeling for meaningful vocabulary and architectural decisions. A temporary hypothesis or ordinary rationale does not automatically need an ADR.
- Deliver a concise decision log and perform or identify the next authorized action.
